# WHOOSH · техничка — нативное iOS-приложение

SwiftUI + MapKit + CoreLocation. Реальный GPS телефона, тёмная карта,
бесконечная генерация самокатов при перетаскивании карты, статусы, заряд, гео.

**Данные о самокатах вымышленные** и генерируются на устройстве
(детерминированный генератор по координатной сетке ~278 м). Приложение
не обращается к системам WHOOSH.

## Как получить .ipa без Xcode на своём Mac

Сборка идёт на серверах GitHub, где Xcode уже установлен. Твой Mac
ничего не компилирует — только заливает файлы.

### 1. Создать репозиторий

1. Открой https://github.com/new
2. Имя: например `whoosh-tech-ios`
3. Public (для публичного репозитория Actions бесплатны без лимита)
4. **Не** добавляй README/.gitignore/license — они уже есть в папке

### 2. Залить эту папку

Папка уже инициализирована как git-репозиторий с одним коммитом.
Осталось добавить remote и запушить (подставь свой логин и имя репозитория):

```bash
cd "/Users/chaika/Documents/Проект по умолчанию/whoosh-ios"

git remote add origin https://github.com/ТВОЙ_ЛОГИН/whoosh-tech-ios.git
git push -u origin main
```

Если git попросит пароль — нужен **personal access token**
(Settings → Developer settings → Personal access tokens → Tokens (classic),
права `repo`), а не пароль от аккаунта.

Альтернатива без терминала: на странице пустого репозитория
«uploading an existing file» → перетащить **содержимое** папки
(`WHOOSHTech/`, `WHOOSHTech.xcodeproj/`, `.github/`, `README.md`).
Папку `.github` в Finder видно через `Cmd+Shift+.`.

### 3. Забрать .ipa

1. Вкладка **Actions** в репозитории
2. Слева `build-ipa`
3. Кнопка **Run workflow** → `Run workflow`
4. Через ~3–5 минут открой завершившийся запуск
5. Внизу, блок **Artifacts** → скачать **WHOOSHTech-ipa**
6. Распаковать zip → внутри `WHOOSHTech.ipa`

Артефакты GitHub хранит 90 дней.

### 4. Установить на iPhone

`.ipa` **неподписанный** — iOS не поставит его напрямую. Нужен
переподписывающий инструмент и бесплатный Apple ID:

**Sideloadly (Windows/Mac)** — https://sideloadly.io

1. Подключить iPhone кабелем, доверять компьютеру
2. Перетащить `WHOOSHTech.ipa` в Sideloadly
3. Ввести Apple ID (создастся бесплатный сертификат)
4. Start

**AltStore** — https://altstore.io — то же самое, но ставится
как приложение на iPhone.

Ограничения бесплатного Apple ID:

| Что | Значение |
|---|---|
| Срок жизни подписи | 7 дней |
| Приложений одновременно | 3 |
| Продление | переподписать через Sideloadly/AltStore |

Платный аккаунт разработчика ($99/год) — подпись на год
и без переподписки.

После установки: **Настройки → Основные → VPN и управление устройством**
→ доверять сертификату разработчика. При первом запуске разрешить
геопозицию.

## Структура

```
WHOOSHTech.xcodeproj/        проект Xcode (objVersion 56, iOS 16+)
WHOOSHTech/
  WhooshTechApp.swift        точка входа
  ContentView.swift          шапка, счётчики, поиск, кнопка GPS
  ScooterCard.swift          карточка самоката и смена статуса
  ScooterMap.swift           MKMapView + кастомные пины
  AppModel.swift             состояние, геометрия, UserDefaults
  LocationProvider.swift     CoreLocation
  Models.swift               модели, генератор, палитра
  Assets.xcassets            иконка и акцентный цвет
.github/workflows/build.yml  сборка .ipa на GitHub Actions
build-local.sh               локальная сборка (нужен Xcode)
make-icon.swift              генератор иконки 1024×1024
```

## Формат номеров

| Длина | Шаблон | Пример | Модель |
|---|---|---|---|
| 4 | 2 буквы + 2 цифры | `HL44` | Ninebot Max Plus (2022) |
| 5 | 3 буквы + 2 цифры | `AJO41` | Ninebot Max Plus Cust |
| 6 | 3 буквы + 3 цифры | `PSB430` | Ninebot SL90 (2024–2025) |

На карте и в карточке номер показывается **без префикса**.
Префикс 4/5/6 служебный: по нему определяется модель.

## Что умеет

- карта MapKit в тёмной теме, пин = код + цвет статуса
- реальный GPS: синяя точка, круг точности, индикатор `±N м`
- кнопка-прицел: центрирует на пользователе и ведёт за ним
- при первом фиксе самокаты переставляются в твой район,
  если ты дальше 1.2 км от Москвы-центра
- карточка: номер, модель, заряд, гео, расстояние от тебя
- статусы: В доступе / Разряжен / LOST / ТС украден
- у украденного — «Последнее гео IoT» и время потери связи
- статусы сохраняются в UserDefaults между запусками
- поиск по номеру: остальные пины гаснут
